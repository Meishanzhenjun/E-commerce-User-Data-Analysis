电商用户价值分析与羊毛党识别
基于Python的电商用户分层与风控分析项目，通过RFM模型、综合评分卡和异常检测算法，实现用户价值评估与羊毛党精准识别。

核心功能
RFM用户分层：基于R小于等于120天、F大于等于2次、M大于等于115元阈值，将2.6万用户划分为8类

羊毛党识别：通过净金额指标（成功金额-退款金额）精准识别757名异常用户，占退款总额80%

综合评分卡：融合5大维度构建0-5分评分体系，自动标注6级用户等级

数据可视化：订单分布、退单率、活跃时段等全维度探索性分析

技术栈
Python · Pandas · NumPy · Matplotlib · Seaborn · RFM模型 · IQR异常检测 · 特征工程

项目成果
识别757名羊毛党，占退款总额80%

定位1,242名核心用户，贡献30-40% GMV

2.6万用户，2.9万笔订单全链路分析

预计提升LTV 15-20%，降低退款损失10万元/周期
